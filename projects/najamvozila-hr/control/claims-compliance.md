# Claims & Compliance — Najam Vozila

THE single canonical home for claim rails. SEO value never overrides factual
truth or compliance. Delete this file only for genuinely unregulated niches.

## Never-claim patterns (machine-scanned)
Hard QC fails any brief/content containing these strings (case-insensitive).
Keep them literal and short.
- sve besplatno
- bez depozita
- najjeftiniji
- broj 1
- tržišni lider
- najpovoljniji
- 100% pokriveno
- jamčimo najnižu cijenu
- bez skrivenih troškova, garantirano

## Rules requiring judgment (qualitative QC + human)
- Never guarantee a specific vehicle model — every fleet reference must carry "ili slično" (or similar) within its category.
- Never fabricate reviews, testimonials, awards, or certifications not genuinely held.
- Never promise insurance coverage for damage types the policy excludes (undercarriage, tyres, glass, interior, clutch, wrong-fuel, negligence-caused damage) unless the actual policy confirms it.
- Never state "od X €" pricing that is not genuinely available at that rate/availability.
- Never imply an official partnership with insurers, airports, roadside-assistance providers, or payment networks unless a genuine contractual partnership exists.
- Soften unverifiable authority claims ("years in business," "X+ satisfied customers," "market leader") to evidence-backed or modest language until real data/proof exists.

## Always verify before publication
- All displayed prices include PDV (VAT) and clearly show any surcharges.
- Insurance/excess (franšiza) terms described match the actual current policy wording.
- Deposit amount, hold method, and release timeline match actual policy.
- Cancellation policy terms match actual policy.
- Cross-border/ferry permission rules, fees, and excluded countries match actual current policy.
- Driver age/licence eligibility rules and any surcharges match actual current policy.
- Delivery/out-of-hours fees, if stated, match actual current policy (currently modeled/unconfirmed — see source-context.md Operations truth).

## Required trust signals / disclaimers
- Prices shown as VAT/PDV-inclusive ("PDV uključen").
- "ili slično" (or similar) disclaimer next to any named vehicle model.
- GDPR / privacy-policy disclosure wherever personal data is collected (booking forms, contracts).
- Clear, accessible deposit, cancellation, and general rental terms (opći uvjeti najma) linked from any page that mentions them.
- Legal classification disclosure where relevant (rental is a tourism service under Zakon o pružanju usluga u turizmu, distinct from leasing and from chauffeured hire).
