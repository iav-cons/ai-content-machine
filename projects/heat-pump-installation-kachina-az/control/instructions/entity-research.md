# entity_research — stage contract (seed-and-expand)

Method: your Entity Research + Content Cluster Ruleset (global, already
loaded) governs HOW. This contract fixes WHAT comes back and how it is judged.

Seed: the packet inlines the operator's pre-project entity analysis from
sources/ marked [PRE-PROJECT SEED — high authority]. It is the starting
point you expand — not a draft you may quietly rewrite and not a finished
answer you may rubber-stamp. Keep its central-entity determination and
salience structure unless you can argue otherwise with evidence; map its
entities into the ruleset's functional classes; add what it lacks. Any
niche-level serp--/paa--/fanout-- files in sources/ are observed-demand
evidence for the same job.

Task: full entity research for the niche and location in the packet. Source
context is factual ground truth; strategy-hypotheses (if present) are
hypotheses to VALIDATE — confirm, adjust, or reject each with a reason.

Required output structure (Required Output 1 of the ruleset), one markdown
artifact with the packet's frontmatter:
1. Niche definition
2. Core entities (weighted: primary / secondary / supporting)
3. Buyer/problem entities
4. Commercial entities
5. Location entities
6. Trust/authority entities
7. Entities to avoid
8. Strategic interpretation (adjacency classes: method / diagnostic /
   problem / symptom / escalation / geographic / audience)
9. SEED DELTA — mandatory when a seed is present, three lists:
   - Added (entities/attributes not in the seed, each with a reason)
   - Changed (seed items you re-weighted, renamed, or re-classed, with reasons)
   - Rejected (seed items you excluded, with reasons)
   An empty delta is a claim that the seed was already complete — say so
   explicitly if you mean it.
10. Hypothesis verdicts (per strategy-hypotheses item: confirmed / adjusted /
    rejected + reason)
11. Document Usage Check table (include the seed as a row)
12. Open items as [ASSUMPTION] / [REQUIRES CONFIRMATION]

Acceptance: source context followed; no invented facts; every entity class
present; seed handled per above with a visible delta; verdicts for every
hypothesis; no cluster map, no URLs, no briefs — that is later work.
