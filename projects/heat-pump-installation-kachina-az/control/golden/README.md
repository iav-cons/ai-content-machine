# Golden examples (consistency lever)

Store ONE approved, best-in-class output per stage here. If a file exists, the
packet generator inlines it into every packet for that stage as "GOLDEN EXAMPLE —
match structure, depth and quality; do not copy content."

Filenames (exact): entity_research.md, content_cluster.md, url_map.yml,
serp_research.md, brief.md, content.md, page_review.md

Update a golden file only via PR when you approve something better — it silently
shapes every future output of that stage.
