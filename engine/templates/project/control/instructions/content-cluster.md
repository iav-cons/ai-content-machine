# content_cluster — stage contract

Method: the Entity Research + Content Cluster Ruleset governs clustering.
Input truth: ONLY the approved canonical entity research in the packet.

Task: intent-based clusters (Required Output 2) — for each cluster: purpose,
search intent, funnel stage, page opportunities, priority, internal-link role.
Plus Required Output 5 (Content Exclusions) and Required Output 6 (Next-step
recommendation). Group by intent and user journey, never keyword similarity.
Every page opportunity needs a justified semantic role; search volume alone is
never permission. Validate against strategy hypotheses with verdicts as in
entity research.

Do NOT produce the URL map, URLs, or slugs here — page opportunities are named
by topic and role only.

Output: one markdown artifact with the packet's frontmatter, cluster table in
the ruleset's format, exclusions list, next-step block, Document Usage Check,
open items as [ASSUMPTION] / [REQUIRES CONFIRMATION].

Acceptance: every cluster traces to entities in the approved research; balance
of commercial/informational stated; cannibalization risks named per cluster.
